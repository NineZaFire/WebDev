เว็บนี้ทำงานอย่างไรบน GitHub Pages

  • GitHub Pages รัน PHP ไม่ได้ จึงโหลด PHP 8.3 แบบ WebAssembly มารันในเบราว์เซอร์ผ่าน Service Worker โค้ด PHP เป็นชุดเดียวกับในโฟลเดอร์ project web

  • ตัวจริงรันด้วย Docker (docker compose up) หรือ XAMPP กับ MySQL ตามที่เขียนใน repo
