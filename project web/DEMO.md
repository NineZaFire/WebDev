# สคริปต์เดโม : LMShirtShop

ประมาณ 15 นาที ทำตามลำดับนี้แล้วจะได้โชว์ rubric ครบทั้ง 11 ข้อ (เลขในวงเล็บ = ข้อใน [RUBRIC.md](RUBRIC.md))
ตัวเลขทุกตัวในสคริปต์นี้มาจากการเดินตามสคริปต์จริงกับข้อมูลตั้งต้น ถ้า import ใหม่ก่อนเริ่ม จอจะขึ้นตรงตามนี้

## ก่อนเริ่ม

- [ ] **import [shirtshop_xampp.sql](shirtshop_xampp.sql) ใหม่ในวันนำเสนอ** ผ่าน phpMyAdmin แท็บ Import
  - Docker : http://localhost:8081 ผู้ใช้ `shop` รหัส `shop_pass`
  - XAMPP : http://localhost/phpmyadmin ผู้ใช้ `root` ไม่มีรหัส
  - วันที่ของออเดอร์และโปรโมชั่นจะเลื่อนมาเป็น "วันนี้" และโปร "ลดกลางเดือน 15%" จะหมดเขตวันนั้นพอดี
  - ถ้าซ้อมแล้วให้ import ใหม่อีกรอบ เพราะเลขออเดอร์และยอดในสคริปต์อิงข้อมูลตั้งต้น
- [ ] เปิดเว็บที่ http://localhost:8080 (ถ้าไม่ขึ้น : เปิด Docker Desktop แล้วรัน `docker compose up -d` ในโฟลเดอร์โปรเจกต์)
- [ ] เตรียมรูป JPG หรือ PNG อะไรก็ได้ 1 รูป (ไม่เกิน 5 MB) ไว้แนบเป็นสลิป
- [ ] เปิดหน้าต่าง InPrivate/Incognito (จะได้ไม่มีตะกร้าหรือการเข้าสู่ระบบค้าง) กด F12 แล้วกด Ctrl+Shift+M เลือกจอกว้าง 390px และเปิดแท็บ Network ไว้โชว์ Ajax
- [ ] เปิด VS Code ไว้ที่ [RUBRIC.md](RUBRIC.md), [assets/style.css](assets/style.css), [assets/app.js](assets/app.js)

## 2. ฝั่งลูกค้า บนจอมือถือ (6 นาที)

**2.1 หน้าแรก** (4, 5, 6, 8, 10)
- แบนเนอร์ดึงโปรจริงจากฐานข้อมูล : "หมดเขตวันนี้ · ลด 15% ทุกสินค้า · กรอกโค้ด WELCOME50 ในตะกร้า ลดเพิ่ม ฿50 เมื่อซื้อครบ ฿500"
- กดชิป "เสื้อยืด" → เหลือ 4 รายการโดยไม่โหลดหน้าใหม่ ชี้แท็บ Network ที่เรียก `api/products.php` แล้วได้ JSON (10)
- กดปุ่มตัวกรองขวาสุด → แผ่นตัวกรองเลื่อนขึ้น (6) → เลือก "฿300 ถึง ฿600" → ปุ่มเปลี่ยนเป็น "แสดง 3 รายการ" ทันที → กดปุ่มนั้นเพื่อปิดแผ่น
- ปิดโหมดมือถือ (Ctrl+Shift+M) ให้ดูจอใหญ่ : ตัวกรองกลายเป็นแถบซ้าย มีจำนวนสินค้าข้างหมวด และมี footer (5) แล้วเปิดโหมดมือถือกลับ
- ช่องค้นหาพิมพ์ "เสื้อยืด" → เจอเสื้อยืดทั้ง 4 ตัว แม้ชื่อสินค้าเป็นภาษาอังกฤษ เพราะค้นจากชื่อหมวดและรายละเอียดด้วย (8)
- แท็บ Elements ใน DevTools : โครงหน้าเป็น `<header>` `<nav>` `<main>` `<section>` `<footer>` ทุกหน้ามาจาก include เดียวกัน (4)

**2.2 สมัครสมาชิก** (3, 6) ไม่ต้องสมัครจริง
- กรอกชื่อ นามสกุล อีเมลให้ครบ แล้วเบอร์โทรใส่ `12345` กด "สมัครสมาชิก" → เบราว์เซอร์เตือนที่ช่องเบอร์โทรเพราะไม่ตรง `pattern` (3) (ถ้าช่องก่อนหน้ายังว่าง เบราว์เซอร์จะเตือนช่องนั้นก่อน)
- รหัสผ่านพิมพ์ครบ 8 ตัว → ข้อความ "อย่างน้อย 8 ตัวอักษร" เป็นสีเขียว (6) · ยืนยันรหัสผ่านให้ไม่ตรง → กรอบแดงและข้อความ "รหัสผ่านทั้งสองช่องไม่ตรงกัน" (3 JS)

**2.3 เข้าสู่ระบบ** (9) `somchai@test.com` / `password123` และติ๊ก "จดจำอีเมล"

**2.4 หน้าสินค้า** (2, 10)
- Graphic Tee ลายแมว → ไซซ์ M → กด + เป็น 2 → "เพิ่มลงตะกร้า" → แถบ "เพิ่มลงตะกร้าแล้ว" (CSS เลือกด้วย `#toast`) และตัวเลขบนตะกร้าเป็น 2 ผ่าน XMLHttpRequest
- Basic Tee ผ้าคอตตอน → ไซซ์ L → "เพิ่มลงตะกร้า" → ตัวเลขเป็น 3

**2.5 ตะกร้า** (10 : Ajax 3 จุดในหน้าเดียว)
- ราคาสินค้า ฿1,000 · โปร "ซื้อ 2 แถม 1 หมวดเสื้อยืด" −฿300 (ระบบเลือกโปรที่ลดได้มากที่สุดให้เอง) · ค่าจัดส่ง ฿40 · รวม ฿740
- ใส่โค้ด `WELCOME50` → "ใช้โค้ด" → รวม ฿690 และขึ้น "ซื้อเพิ่มอีก ฿350 ส่งฟรี"
- กด + ที่ Graphic Tee → ค่าจัดส่งเป็น "ส่งฟรี" รวม ฿1,000 → "ไปชำระเงิน"

**2.6 ชำระเงิน** (6)
- QR PromptPay วาดเมื่อหน้าโหลดเสร็จ (window load event) ยอด ฿1,000 ฝังอยู่ใน QR (เลขพร้อมเพย์ของร้านเป็นเลขจำลอง สแกนจ่ายจริงไม่ได้)
- แตะกล่องแนบสลิป → เลือกรูปที่เตรียมไว้ → "ยืนยันคำสั่งซื้อ" → หน้าสั่งซื้อสำเร็จ **#LM-1083**
- พูด : สร้างออเดอร์ ตัดสต็อก และบันทึกสลิปใน transaction เดียว ([public/checkout.php](public/checkout.php))

**2.7 คำสั่งซื้อและบัญชี** (9)
- "ดูคำสั่งซื้อ" → #LM-1083 อยู่บนสุด สถานะ "รอตรวจสลิป" (ดึงจากฐานข้อมูลตามผู้ใช้ใน session)
- แท็บ "บัญชี" → การ์ด "การเข้าสู่ระบบครั้งนี้" แสดงเวลาเข้าสู่ระบบและรหัส session → "ออกจากระบบ" → หน้าเข้าสู่ระบบยังจำอีเมลไว้ (cookie)

## 3. ฝั่งแอดมิน บนจอใหญ่ (6 นาที)

ปิดโหมดมือถือ แล้วเข้าสู่ระบบ `admin@shirtshop.test` / `admin123` จะเข้าแดชบอร์ดเลย

**3.1 แดชบอร์ด** (7, 11) ยอดวันนี้ · "ตรวจสลิป 4 ออเดอร์" · สินค้าใกล้หมด · โปรใกล้หมดเขต · กราฟ 7 วัน ดึง JSON จาก `api/report.php` (ชี้แท็บ Network)

**3.2 ตรวจสลิป** เมนู "ออเดอร์" → การ์ด #LM-1083 มีรูปสลิป
- กด "ปฏิเสธ" ให้ดูว่าระบบถามเหตุผลก่อน แล้วกดยกเลิก
- กด "ยืนยันการชำระ" → ข้อความ "ยืนยันการชำระ #LM-1083 แล้ว"

**3.3 รายงาน** (11, 3) เมนู "แดชบอร์ด" → ลิงก์ "ดูรายงาน" ที่การ์ดกราฟ
- ปุ่ม 7 วัน / 30 วัน / 12 เดือน และ "ดูเป็นตาราง"
- กรอกวันที่ 1 ของเดือนนี้ถึงวันนี้ → "ดูรายงาน" → ตารางมีแถวเท่าจำนวนวันในช่วง (11 กรอกข้อมูลเปลี่ยนเงื่อนไข)
- ลองให้วันสิ้นสุดอยู่ก่อนวันเริ่ม → กดแล้วไม่ส่ง (3 JS) · ลองช่วงเกิน 92 วัน → เซิร์ฟเวอร์ขึ้นข้อความใต้ฟอร์ม

**3.4 สินค้า** (8, 6)
- ค้นหา `Polo` → 3 รายการ · ชิป "ใกล้หมด" → 5 รายการ · ชิป "ทั้งหมด" แล้วไปหน้า 2 → "แสดง 8 ถึง 12 จาก 12 รายการ"
- เปิดแก้ไข Classic Polo → ไซซ์ S เป็น 0 มีป้าย "หมด" → กด + → ป้ายเปลี่ยนทันที · "เพิ่มรูป" เลือกรูป → รูปตัวอย่างโผล่ก่อนบันทึก (6) → กดเมนู "สินค้า" กลับไปโดยไม่บันทึก

**3.5 นำเข้า JSON และลบสินค้า** (7, 8)
- หน้าสินค้า → "นำเข้า JSON" → "ดาวน์โหลดไฟล์ตัวอย่าง" → เลือกไฟล์นั้น → ตารางตัวอย่าง 3 รายการ (JS อ่านไฟล์แล้วสร้างแถว) → "นำเข้า 3 รายการ"
- ขึ้น "นำเข้าสินค้า 3 รายการแล้ว" ทั้งหมด 15 รายการ (7 : ข้อมูลจาก JSON เก็บลงฐานข้อมูล)
- เปิด Puffer Jacket → "ลบสินค้านี้" → ยืนยัน → "ลบสินค้าแล้ว" เหลือ 14 (8 : Delete สินค้าที่ยังไม่มีคนสั่ง ถ้ามีคนสั่งแล้วระบบไม่ให้ลบ)

**3.6 โปรโมชั่น** (7, 10)
- ปิดสวิตช์ "ลดกลางเดือน 15%" → เปิดแท็บใหม่ไปที่ http://localhost:8080 → แบนเนอร์หน้าร้านเปลี่ยนเป็น "ซื้อ 2 แถม 1 หมวดเสื้อยืด" เอง
- "สร้างโปร" → กล่องตัวอย่างราคา "ซื้อเสื้อยืด 3 ตัว ราคาเต็ม ฿900 จ่าย ฿765" → แก้ % ของขั้นส่วนลด → ตัวเลขเปลี่ยนทันที (fetch ไปคิดราคาด้วยฟังก์ชันเดียวกับตะกร้า)

## ถ้ามีปัญหาระหว่างเดโม

| ยอด เลขออเดอร์ หรือแบนเนอร์ไม่ตรงสคริปต์ | ยังไม่ได้ import ใหม่ หรือซ้อมไปแล้ว ให้ import [shirtshop_xampp.sql](shirtshop_xampp.sql) อีกรอบ |
